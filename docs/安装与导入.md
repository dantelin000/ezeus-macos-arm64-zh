# eZeus ARM Mac 程序与汉化补丁

适用：Apple Silicon（M1/M2/M3/M4 及后续 ARM Mac），macOS 15 或更高。本包复用已测试的 eZeus 0.8.1-Beta.8 ARM 程序及 45 个随包动态库；无需 Homebrew、Python、Rosetta 或重新编译。虽然主程序标记 macOS 14，随包动态库要求 macOS 15，因此本包以 15 为最低系统版本。

## 此分发包不含原版游戏素材

不包含正版游戏的 DATA、音频、影片、地图、原始 ENG/XML、Windows 程序、存档，也不包含 eZeus 的 interface.e、i15.e、i30.e 等贴图缓存。专用中文补丁只含差异译文、界面翻译、战役译文、自由字体和安装工具，不能单独运行。

## 先准备两份合法来源的资料

1. 购买含《宙斯》和《波塞冬》的完整英文版，例如 [GOG 的 Zeus + Poseidon (Acropolis)](https://www.gog.com/en/game/zeus_poseidon) 或 [Steam 的 Zeus + Poseidon](https://store.steampowered.com/app/566050/Zeus__Poseidon/)。在可安装该游戏的环境完成安装，把完整游戏目录复制到 Mac。也可使用自己已合法解压的安装内容。若使用 GOG 离线 Windows 安装包，可另行使用 innoextract 静态提取；选提取后包含 DATA 的 app 目录。
2. 从 [eZeus 官方 0.8.1-beta 发布页](https://github.com/MaurycyLiebner/eZeus/releases/tag/0.8.1-beta) 下载并解压 `eZeus-0.8.1-beta.zip`，准备引擎资源目录。无需运行其中的 Windows EXE。只下载 ARM 二进制压缩包不能代替这份资源包。

正确目录大致如下：

```text
正版游戏根目录/
  DATA/                 （包含 Zeus 与 Poseidon 的 231 个素材文件）
  Audio/
  Adventures/
  Model/
  Zeus_Text.eng
  Zeus_MM.eng

官方 eZeus 资源目录/
  interface.e
  i15.e 和／或 i30.e
  Adventures/
  Sanctuaries/
  Text/language.txt
```

不要选择 setup.exe、ZIP、ISO、只有《宙斯》本体的目录，或单独一个 DATA 子目录。原版 Windows EXE 不会被安装或运行；导入器在本机读取你自己的英文 ENG 生成所需 XML。

## 安装与导入

1. 把 `eZeus ARM.app` 拖入“应用程序”。
2. 启动它，选择“导入素材”，依次选择上面的正版游戏根目录和 eZeus 资源目录。
3. 导入器检查素材清单、8248 条文字和 980 条消息，再复制到本机用户资料目录；原始购买目录不修改。
4. 如需中文，退出游戏，再运行独立包中的 `eZeus 中文补丁.app`，选择“安装汉化”。重新启动 `eZeus ARM.app` 后即使用中文。补丁会检查本版引擎 SHA-256、英文条目指纹及战役键名，版本不匹配时拒绝写入。需要恢复英文时，在同一工具选择“恢复英文”。

## 数据、存档和更新

运行数据：`~/Library/Application Support/eZeusMac-0.8.1-Beta.8/`

存档：`Runtime/Save/`；日志：`Logs/`；重新导入前的资料与旧存档：`Backups/`。可在访达按 Shift+Command+G 输入上述路径。

导入会复制素材，占用约 1.1 GB 空间。重新导入时会另留完整备份，需要额外空间；旧存档和设置会复制回新运行目录。更新 `.app` 不覆盖数据目录。导入和补丁工具会阻止同时运行游戏或写入；操作前先保存退出。

补丁只适配这里的 eZeus ARM64 0.8.1-Beta.8 包，不适用于零售 Windows 原版、其他引擎版本或任意中文整合版。程序写死的难度名称保留英文；部分教程图示由文字注明“图示略”；长中文保留折行空格。

本包使用本机临时签名，未做 Apple 开发者签名或公证。如果 macOS 阻止首次打开，核对来源后按系统“隐私与安全性”的“仍要打开”流程操作；不要关闭系统安全保护。

## 只给维护者的命令行入口

图形界面不需要这些命令。CLI 与图形导入共用同一实现，可指定隔离数据目录测试。

```sh
APP="/Applications/eZeus ARM.app"
"$APP/Contents/MacOS/eZeusLauncher" --import --game "/path/to/正版根目录" --engine-resources "/path/to/eZeus资源目录"
"$APP/Contents/MacOS/eZeusLauncher" --verify
```

引擎：[eZeus](https://github.com/MaurycyLiebner/eZeus)；ARM 程序：[MacThings 发布页](https://github.com/MacThings/eZeus/releases/tag/Zeus-Binaries)。许可证、源码快照和本包辅助工具源码随程序保留。游戏需自行购买，工具不包含购买资格检查或 DRM 绕过。
